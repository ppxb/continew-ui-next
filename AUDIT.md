## 总体结论

- **复用基础已建立，但正确性仍有欠账**：`DataTable / EntityDrawer / ListPageCard / QueryState / DeleteConfirmDialog` 已形成公共层；不能据此概括 Query/Form/Table 用法全部规范，分页模型、缓存失效和状态订阅存在已确认问题。
- **优先处理可观察行为**：登录默认凭据仍存在；长 ID 数值转换、角色与字典分页、站点缓存长期不更新、租户提交期间取消、角色选人截断均需优先处理。富文本条目保留为需明确净化边界的条件性安全风险。
- **自研树组件补审发现根层问题**：三级级联遗漏祖先、数字 key 导致误选父节点、复选框键盘事件重复处理、清除入口及树层级/焦点语义不完整；另有搜索展开状态分离、异步选中展开、重复索引及深链复杂度问题，按影响分别分级。
- **刚拉取的提交已纳入**：`6ae6a9a → 63437d8` 包含 `254ee3d`（详情查询复用）、`5434ed4`（FilterSelect 长标签）和 `63437d8`（TextCell 复用）；未发现新增 P1/P2 回归。R05/R06 保留已修复，TextCell 换行契约另记 S09；R01/R03/R04 历史修复与 R02 部分迁移状态保留。
- **原报告存在误判**：统一 HTTP 提示、提交锁、前置整体校验、详情刷新门禁不能机械删除；原生 HTML、额外 class、未用 memo、较大的 mock 文件也不自动等于问题。先修行为，再以实际维护与测量收益决定抽象或优化。
